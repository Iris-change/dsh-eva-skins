DeepSeek Harness · EVA 皮肤合集（macOS）

1. 终端里执行：  bash install-mac.command
2. 出现 Done! 后，Cmd+Q 彻底退出 DeepSeek Harness
3. 重新打开，输入框左侧出现 ● UNIT-02 ▾ 胶囊
   面板里切换：默认 / 二号机 / 零号机 / 初号机 / 八号机
   快捷键：Control+Option+U 开关皮肤，Control+Option+B 重播开机动画

卸载：  bash uninstall-mac.command

更快的装法（有 npm 的话）：
   dsh plugin --profile desktop add dsh-eva-skins
